AndChamber 把 OpenChamber（OpenCode 的 Web 界面）带到你的 Android 手机上。OpenCode 是编程助手。AndChamber 可以在手机上本机运行，也可以连接你电脑上的 OpenChamber 服务。

两种使用方式：

* 本机模式（arm64-v8a 和 x86_64 设备）：AndChamber 在应用私有目录中用 PRoot 搭建一个精简的 Alpine Linux 环境，无需 root。首次设置会下载 Alpine Linux、Node.js、Git 等运行时组件，再安装 OpenChamber 和 OpenCode，需要网络连接并需要一些时间。
* 远程模式：添加你电脑或其他受控机器上 OpenChamber 服务的地址。明文 HTTP 需要手动确认。

本机模式说明：

* 前台服务会在应用使用期间管理本机运行时，切到后台后服务仍会继续运行。但这不保证 24 小时持续运行，Android 仍可能停止后台工作。
* 打开应用时，可以恢复你上次使用的 OpenChamber 实例和页面。

通知：

* 应用在后台时，OpenChamber 的回复完成、出错、提问和权限请求等事件可以作为 Android 通知出现。
* 在通知中可以回复、允许或拒绝权限、回答简单问题；点击通知会打开对应会话。

公共目录（可选，默认关闭）：

* 可以开启 /sdcard/AndChamber/ 作为项目和 OpenCode 配置的公共目录，便于用文件管理器或 USB 编辑。
* 此功能需要“所有文件访问”权限。其他拥有该权限的应用也能读取此目录，请不要在其中保存 API Key 或其他机密。
* 会话数据、登录信息和插件依赖仍保存在私有目录。

实验性浏览器（可选）：

* 首页有一个独立的 Browser，使用自己的 WebView 配置，不会复制 OpenChamber 页面的 Cookie。
* Agent 控制默认关闭。请先在聊天中发出任务，再在前台打开 Browser 并自行授权。离开页面或触摸页面接管后授权会结束，之后需要重新授权。
* 仅支持公网 https 页面，支持范围有限，许多页面、登录流程和复杂表单可能无法使用。该功能处于早期阶段，尚未在手机上完成端到端验证。

系统要求：

* Android 8.0（API 26）或更高版本。
* 内嵌页面需要支持多 Profile 的系统 WebView。页面提示更新时，请更新 Android System WebView 或 Chrome。
* 本机模式需要 arm64-v8a 或 x86_64 设备。
* 首次设置需要网络连接以下载运行时组件。
* AndChamber 不包含模型、模型权重、模型服务、账号或订阅。请在 OpenChamber 中单独配置模型和服务商。模型运行在哪里（互联网服务商、你自己的服务器或局域网），以及费用如何，取决于你选择的服务商。

界面支持英文和简体中文，跟随系统语言。这是 0.x 预发布版本。
