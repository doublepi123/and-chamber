## 新功能

- **系统通知与快捷回复**：App 在后台时，OpenChamber 的完成、出错、提问、权限请求、目标完成等通知会以 Android 通知送达。
  - 完成 / 出错：在通知上直接回复，消息发到对应会话。
  - 权限请求：通知上「允许一次 / 始终允许 / 拒绝」。
  - 简单提问（单个选择题或单个文本框）：在通知上直接回答。
  - 点通知直接打开对应会话。
  - AndChamber 自身的运行错误（安装失败、启动失败、服务反复退出、OpenCode 后端出错）也会通知。
- **中英双语**：界面、通知、错误信息跟随系统语言显示中文或英文。
- **项目挂到 `~` 下**：开启公共目录后，`/sdcard/AndChamber/projects` 挂载为 `~/projects`，私有工作区为 `~/projects-private`；默认工作目录为 `~`。旧的 `/workspace` 路径已移除，之前在 `/workspace` 下创建的会话需从 `~/projects` 重新打开。
- **公共配置目录**：整个 `/sdcard/AndChamber/opencode/` 作为 OpenCode 全局配置目录，App 内外的修改双向生效；`service.json` 与 `node_modules` 仍保存在私有目录。

## 修复

- 修复 Android 13 及以下设备可能因 `Path.of`（API 34）崩溃的问题。
- PRoot 更新到 5.1.107.97（旧版本已从 Termux 镜像下架）。
- 首页项目文件夹卡片中 projects 行重复显示的问题。

## New

- Android notifications for OpenChamber (finished, error, question, permission, goal) with quick replies, permission buttons and simple form answers; tapping opens the session. AndChamber runtime errors are notified too.
- English and Simplified Chinese UI, following the system language.
- Projects mounted under `~` (`~/projects`, `~/projects-private`); `/workspace` removed.
- The whole shared `opencode/` folder is OpenCode's global config folder; `service.json` and `node_modules` stay private.

## Fixes

- Crash on Android 13 and earlier (`Path.of` is API 34).
- PRoot 5.1.107.97 (5.1.107.96 was removed from Termux mirrors).
