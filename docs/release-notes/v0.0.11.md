## 新功能

- **每个 OpenChamber 实例各自记住上次的页面**：本机服务器和每个远程服务器都会记住各自最后打开的页面（例如某个会话）。在多个实例之间切换时，回到某个实例会直接回到它上次所在的会话，而不再回到起始页。启动时仍会打开最后使用的实例和它的页面；通知中打开的会话仍然优先。
- 回到首页只会忘记“最后使用的是哪个实例”，不会清除各实例记住的页面。服务器地址改变后，旧页面不再使用；删除远程服务器时，它记住的页面也一并删除。
- 从旧版本升级时，原来记住的那一个页面会归到最后使用的实例，无需操作。

## New

- **Every OpenChamber instance remembers its own last page**: the on-device server and every remote server each remember the page you last had open (for example a session). Switching between instances brings you back to where each one was left, instead of its start page. Launch still opens the last used instance at its page, and a session opened from a notification still wins.
- Going Home only forgets which instance was last used; each instance keeps its page. A server whose address changed drops its old page, and removing a remote server also drops its page.
- On upgrade, the single page remembered by older versions moves to the last used instance; nothing to do.

## Other

- 536 JVM unit tests and 72 Python checks pass.
- Verified on an x86_64 emulator (Android 15) with two remote servers: switching A and B back and forth returns each to its own session, a force-stop and cold launch returns to B's session, and removing B clears only B's record.
- On-device server path: verified on an x86_64 emulator (Android 15) with the later main build (e4bc270, which adds x86_64 on-device server support; the UI code is the same as in this release). Switching between the on-device and a remote server returns each to its own session; a force-stop and cold launch on either returns to that instance's session; after stopping and starting the on-device server (same address), reopening it returns to the same session. In this release the on-device server still supports arm64-v8a only.
- Upgrade: verified with debug builds of v0.0.10 and of this feature's commit. After the upgrade the page remembered by the old version moves to its instance and the old keys are removed; a cold launch, and reopening from Home, both return to the same session. The release APKs were checked for checksum, version and signature only.
