## 新功能

- **支持 Cloudflare Access 保护的远程服务器**：远程 OpenChamber 放在 Cloudflare Access 后面时，App 会识别 Access 的跳转和认证质询，在该服务器专属的 WebView 里打开 Access 登录页；登录完成回到服务器后自动继续加载 OpenChamber。之后的健康检查、会话探测和登录请求会带上该服务器 Profile 中的 Access Cookie（`CF_Authorization`）。识别到 Access 时不会发送 UI 密码。

## 其他

- 仓库新增公开仓库隐私规则（`AGENTS.md`）。

## New

- **Remote servers behind Cloudflare Access**: AndChamber detects Access redirects and authentication challenges, opens the Access login page inside that server's own WebView profile, and continues to OpenChamber after the login returns to the server. Health checks, session probes and login then carry that profile's Access cookies (`CF_Authorization`). The UI password is never sent while Access is gating the server.
