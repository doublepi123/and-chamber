# v0.0.34 — 代理说完成，不再弹大卡片

> An agent's own finish shows a light note instead of a full check card.

## 改进

- **代理自己报告完成时，只显示一条小提示**：以前每个任务结束后，手机操控页都会被一张“已结束 · 请核对结果”的大卡片占满，必须点“关闭”才能回到正常页面。现在，如果是代理在正常授权下自己报告完成（没有停手、没有结果不确定的操作），只在页面顶部显示一行“代理报告已完成”，并说明“结果未自动核实”。可以点“打开 App”去看一下，也可以直接点“知道了”。页面其他部分保持正常可用。状态条显示为“已完成（未核实）”。
- **你主动结束、接管或结果不确定时，仍显示完整的核对卡片**：这些情况更可能出现重复提交或操作只做了一半，所以仍然提醒你去核对。
- **旧的结果卡不再挡住自动恢复**：OpenChamber 重启后，一张没关的结果卡不再被当成“还有任务没处理完”，不会阻止“已暂停”自动解除。

## 验证范围

- 模拟器（API 35 / x86_64）上的独立测试包和测试 App：代理报告完成后，只显示一条小提示，页面仍是“可以在聊天里使用”；点“知道了”后提示消失，任务状态清空。你在原生页面结束任务时，仍显示完整的“待核对”卡片。
- 2,079 项 JVM 测试通过，lint 和 debug/AndroidTest 打包通过。
- 还没在真机上复测。

## Improvements

- **An agent's own finish shows a light note**: a task the agent itself reported finished, on a clean live grant (no stop, nothing uncertain), no longer takes over the phone-control screen with a full "check the results" card. A one-line "The agent reported it's done — not verified automatically" note appears above the normal page with "Open app" and "Got it"; the status line says "Done (not verified)".
- **Person stops, take-overs and uncertain ends keep the full check card**, since those are where a repeated or half-done action is most likely.
- **An old result card no longer blocks the automatic resume** after an OpenChamber restart.

## Verification scope

- On an API 35 / x86_64 emulator with a separate test package and the synthetic target: after a model finish only the light note appears and the page stays ready for chat; "Got it" clears it and the retained task. A native End still shows the full check card.
- 2,079 JVM tests passed, with lint and debug/AndroidTest packaging.
- Not yet re-tested on a real phone.
