## 新功能

- **x86_64 设备支持本机服务器**：本机模式现在同时支持 arm64-v8a 和 x86_64（例如 x86_64 的 Android 模拟器）。之前 x86_64 只能连接远程服务器。其他架构仍只能连接远程服务器。
- 原因：Android 在 x86_64 上的应用 seccomp 策略拒绝原始 `fork` 系统调用。PRoot 从 5.1.107.97 升级到官方 5.1.107.98，后者把 guest 中的 `fork` 改为 `clone(SIGCHLD)` 执行，并恢复寄存器，因此 Linux 环境中的进程创建可以正常工作。

## New

- **On-device server on x86_64**: local mode now supports x86_64 (for example an x86_64 Android emulator) as well as arm64-v8a. Before, x86_64 could only use remote servers. Other ABIs still use remote servers only.
- Why: Android's x86_64 app seccomp policy rejects the raw `fork` syscall. PRoot is upgraded from 5.1.107.97 to the official 5.1.107.98, which runs the guest's `fork` as `clone(SIGCHLD)` and restores registers, so processes in the Linux environment can be created normally.
