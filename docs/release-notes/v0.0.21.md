## 新功能

- **本机运行时可选屏幕常亮**：在本机服务器“详情”中开启后，仅当服务器正在运行且 AndChamber 位于前台时保持屏幕常亮。默认关闭；停止运行或离开应用后恢复正常休眠，不申请 WakeLock，也不影响远程服务器页面。

## 修复

- **实例与地址**：修复部署在子路径下的 OpenChamber 实例在切换实例或恢复进程后重复拼接路径的问题。地址编辑器在保存前拒绝用户名/密码，历史地址在列表中也不再显示 userinfo。
- **远程数据移除**：移除远程服务器时，同时清理该服务器命名 WebView profile 中的 Cookie 和网站存储；清理期间阻止迟到写入，失败时保留服务器配置并提示，而不是虚报删除完成。
- **通知快捷回复**：同一会话的多条通知使用各自独立的回复 PendingIntent，发送状态、失败草稿和自动清理不再落到另一条通知。
- **代理控制权**：普通“重新加载页面”不再解除用户接管。操作结果未确认且代理仅可读取时，窗口会明确显示只读状态，并可直接“接管”撤销读取权限。
- **浮动浏览器反馈**：SPA 地址变化和被策略阻止的导航会立即更新窗口地址或错误状态，旧页面的迟到回调不会污染当前页面。
- **短窗口与大字体**：连接、错误和本地状态面板在高度不足时可滚动，全部说明和操作按钮都能到达。

## Added

- **Optional screen awake for the local runtime**: a new switch in the local server's Details keeps the screen on only while that server is running and AndChamber is in the foreground. It is off by default, releases when the server stops or the app leaves the foreground, uses no WakeLock and does not affect remote pages.

## Fixed

- **Instances and addresses**: restoring an OpenChamber instance mounted at a subpath no longer appends that subpath twice after switching instances or recreating the process. The address editor rejects userinfo before saving, and previously saved addresses no longer display it in the server list.
- **Remote data removal**: removing a remote server now also clears cookies and website storage from its named WebView profile. Late writes are blocked during cleanup; a failed cleanup keeps the server configuration and reports the problem instead of claiming deletion.
- **Notification replies**: notifications belonging to one session use distinct reply PendingIntents, so sent states, retained drafts and cleanup stay with the notification that was actually used.
- **Agent authority**: an ordinary Reload no longer clears an explicit takeover. When an action outcome is uncertain and the agent has read-only access, the window exposes that state and offers Take over to revoke the remaining access.
- **Floating-browser feedback**: SPA address changes and policy-refused navigations now update the visible address or error state immediately, while late callbacks from an old page are ignored.
- **Short windows and large fonts**: connection, error and local-state panels scroll when space is limited, keeping every message and action reachable.
