## 新功能与改进

- **多页面浏览**：浮动浏览器地址区域显示当前页和总页数，可打开页面列表切换或关闭页面。菜单可新建页面，使用独立空地址输入；后台页标题持续更新，关闭当前页后自动选择相邻页面。切换页面仍撤销代理授权，不自动恢复。
- **本地实例独立保活**：打开或切换远程实例不再销毁本地 WebView。本地页面和当前远程页面分开保留，返回本地时保留原页面、会话与滚动状态；远程页面之间仍按原策略替换。

## Added and improved

- **Multi-page browsing**: the floating browser now shows the current page number and total count. A page list supports switching and closing pages, while More > New page opens a separate empty address editor. Background titles stay current, and closing the shown page selects its neighbour. Switching pages still revokes the agent grant and never restores it automatically.
- **Independent local-instance retention**: opening or switching to a remote instance no longer destroys the local WebView. The local page and current remote page are retained independently, so returning to the local instance preserves its page, session and scroll state. Remote pages are still replaced by the next remote target as before.
