## 改进

- **代理打开网页后的提示**：代理刚打开的页面在等你允许时，浏览器小窗会显示“代理打开了这个页面。点“允许代理”后，它才能操作。”。之前显示的是“你正在自己浏览…”，容易误解。
- **允许后代理自动继续**：代理打开网页后，会等你点“允许代理”，最长约 1 分钟。你点了之后，代理马上就能读取和操作页面，不用再发一条“继续”。超过时间没点、取消、接管或关闭标签页时，代理会照旧提示你去点“允许代理”。等待期间不会自动授权。

## Improved

- **A clear prompt after the agent opens a page**: while a page the agent opened waits for you, the browser window says "The agent opened this page. Tap Allow agent to let it use the page." It used to say "You are browsing…", which was misleading.
- **The agent carries on after you allow it**: after opening a page, the agent waits up to about a minute for you to tap **Allow agent**. Once you do, it can read and use the page straight away; you don't need to send "continue". If you don't tap in time, cancel, take over or close the tab, the agent asks you to tap Allow agent as before. Nothing is allowed automatically while it waits.
