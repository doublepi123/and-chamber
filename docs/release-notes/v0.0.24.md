## 新功能与修复

- **多字段通知表单**：需要多个文本字段的问题不再只显示通知正文。“填写表单”会打开原生输入页，配对端口、配对码、连接端口等可一次填齐并作为同一张 answer map 提交。
- **输入与提交安全**：必填项缺失时不发送，所有字段只提交一次；不同表单的答案互不串用，失败保留输入，不自动重发。
- **通知生命周期**：表单动作绑定独立 revision，旧结果不会覆盖或删除同会话的新通知。保留通知后按钮同步刷新，重开仍可继续提交或关闭。
- **隐私与键盘**：错误只显示固定安全文案，不回显响应体或验证码。软键盘弹出时发送按钮保持完整可见。

## Added and fixes

- **Multi-field notification forms**: questions with several text fields now offer Fill form, opening a native input screen. Pairing ports, pairing codes and connection ports can be completed together and submitted as one answer map.
- **Input and submission safety**: missing required values block submission, and the whole map is sent only once. Answers are isolated by form, preserved after failures, and never automatically resent.
- **Notification lifecycle**: form actions carry independent revisions, so stale results cannot overwrite or remove a newer notification from the same session. Kept actions are refreshed for reopening and later success.
- **Privacy and keyboard**: failures use fixed safe messages instead of response bodies or verification codes. Send remains fully visible above the soft keyboard.
