# v0.0.36 — 浮窗常驻、自动让开、直接看进展

> The capsule stays visible, moves out of the way, and shows progress.

## 改进

- **浮窗一直显示**：以前每次读屏前都会把浮窗隐藏，读完再显示，所以操作过程中浮窗会时隐时现。现在读屏时浮窗一直保持显示，只有截图时才会短暂隐藏，避免截图里带上你写的任务说明和聊天提醒。
- **浮窗挡住目标时自动让开**：如果代理要点、要滑或要输入的位置正好被浮窗挡住，浮窗会先自动收起，移到屏幕另一侧或离目标远的位置，确认不再挡住后才执行操作。实在让不开时只拒绝这一下，任务不会停。自动让开不会改掉你自己拖好的位置。
- **浮窗上直接看进展**：运行中的胶囊显示简短状态、已发出的操作数，下面最多两行显示最新一步（例如已读屏、已点按，或者代理说的话）。接管按钮改成圆形手掌图标，触控区域仍不小于 48dp。读屏时 TalkBack 能读出完整内容，但不会每走一步就自动播报。
- **去掉“未核实”标记**：浮窗、停止卡片和完成提示里，代理说的话不再加“未核实 / 未核验”。你主动结束、接管，或结果说不准时，仍会显示完整的核对卡片，避免重复提交。
- **任务结束后，别的聊天可以直接用手机**：以前第一次使用手机控制的聊天会一直占着手机，其他聊天会提示被占用。现在只有任务进行中或等你处理时才会拒绝其他聊天；任务结束后，同一个 OpenChamber 里的任何聊天都可以直接发起新任务，不用重新设置。

## 验证范围

- 在模拟器（API 35 / x86_64）上，用独立测试包、测试 App 和真实浮窗验证了：浮窗被拖到 Next page 按钮上方后，代理点击这个位置，浮窗自动移开，点击成功并进入第二页，整个过程中浮窗一直显示（抽样 56/56 次都在）；胶囊进展行能完整读出，没有被导航栏挡住；A 聊天任务进行中时 B 聊天被拒绝，A 结束后 B 能直接开始并完成点击，B 进行中时 A 被拒绝。
- 真实浮窗安全测试（读屏时浮窗保持显示、截图不含浮窗、点在浮窗上被拒绝、浮窗移动后按新位置判断、目标 App 要求隐藏浮窗时拒绝操作）和读屏/点击/返回/输入的端到端检查都通过。
- 全部 JVM、Node、Python 测试通过，lint 和 debug/AndroidTest 打包通过。
- 还没在真机上复测；没有验证大字号、横屏、TalkBack 的实际朗读和中文排版。

## Improvements

- **The capsule stays visible**: hierarchy reads no longer hide and re-add the overlay; only screenshots hide it briefly.
- **Automatic make-way**: when a tap, swipe or input focus would hit the capsule, it collapses and moves aside once, is re-verified from the real window frame, and only then is the action sent; otherwise just that action is refused as `OVERLAY_OBSTRUCTED`. The automatic move is not saved as your own position.
- **Progress on the capsule**: a short status, dispatch count and up to two lines of the latest step or agent note; Take over is a 48dp icon button; TalkBack reads the full text without announcing every step.
- **No "not verified" labels** on agent notes; person ends, take-overs and uncertain stops keep the full check card.
- **Other chats after a task ends**: another chat is refused only while a task is live or waiting; afterwards any chat on the same runtime may start the next task.

## Verification scope

- API 35 / x86_64 emulator with a separate test package, synthetic target and the real overlay: a tap under the capsule made it move away and succeed with the overlay visible throughout; the progress line was fully readable; the A/B chat handoff behaved as above. Real-overlay safety instrumentation and real-driver end-to-end checks passed.
- All JVM, Node and Python tests, Android lint and debug/AndroidTest packaging passed.
- Not re-tested on a real phone; large font, landscape, TalkBack speech and Chinese layout were not checked.
