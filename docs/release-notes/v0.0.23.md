## 修复与改进

- **手动控制交接**：撤销代理授权后，当前有效页面真正切换为手动控制，用户可以继续使用其中的链接和表单，不会自动恢复代理授权。页面替换、加载失败和明确接管仍遵循各自规则。
- **Back 键行为**：先关闭页面列表，再退出地址编辑；用户选择的全屏在小窗可放下时返回小窗，自动全屏或折叠态则隐藏浏览器，避免按键误传到被遮挡的聊天页。
- **工具请求身份与取消竞态**：请求接纳和取消统一使用 `(session, request)` 身份。已取消请求不会因容量释放或重复发送而被重新执行。
- **CI 稳定性**：提交导航测试改为等待替换页实际创建完成，并保留有界超时，修复慢速 CI 上偶发的 `expected:<2> but was:<1>`。

## Fixes and improvements

- **Manual-control handoff**: after a grant is revoked, links and forms work in the current valid page without automatically restoring agent access. Replacement pages, failed documents and explicit takeover keep their own rules.
- **Back navigation**: dismiss the page list first, then leave the address editor. A user-requested full screen returns to the small window when it fits; automatic full-screen and folded states hide the browser instead of leaking Back to the covered chat.
- **Tool request identity and cancellation**: request claims and cancellation now share the same `(session, request)` identity, so a cancelled call cannot be re-admitted after capacity is released or the call is repeated.
- **CI stability**: submit-navigation tests wait for the replacement page to be created, with a bounded timeout, fixing the intermittent slow-CI `expected:<2> but was:<1>` failure.
