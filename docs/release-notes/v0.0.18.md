## 修复

- **浏览器不再因读取失败就要求重开**：区分“上次动作结果未确认”和“页面文档已失效”。快照、截图失败或滚动回执丢失，不再单凭错误码封住整个页面；失败的操作仍返回错误，不自动重做。
- **未确认操作可先观察**：点击、输入或回车提交已经发出，但结果未确认时，同一页面在原有权限和文档校验仍有效的情况下可以继续快照、截图。代理不能继续修改或通过新开页面绕过限制；你核对页面后点“交给代理”才恢复操作，之前的动作不会重放。
- **恢复按钮与状态一致**：页面仍可观察时提示“上次操作未确认，核对后交给代理。”；文档确实失效时改为可用的“重新打开”，不再提供点了也无法恢复的“交给代理”。重新打开保留标签页及桌面分辨率；渲染器失效后也保留恢复入口，不再无限显示加载状态。
- **保留权限边界**：接管、退到后台、连接或会话变化仍会撤销权限。修复定向打开非当前标签页可能清掉未确认状态的绕过路径；恢复校验期间出现新的未确认操作，也不能被迟到的授权覆盖。
- **工具提示更准确**：`OUTCOME_UNKNOWN` 不再一律要求重开。只读观察结果明确标记 `drivable:false`、`observationOnly:true`，不会把“能看页面”误报成“能继续操作”。

- 992 项 JVM 测试、292 项 Node 测试通过，Android lint 无错误；另有 1 项可选上游源码检查因未提供源码跳过。
- Android 15 / x86_64 模拟器上，19 项恢复、提交、桌面视口、授权和站点数据回归通过；最后的恢复与提交改动另复测 8 项通过。本地插件传输、重启和冷启动通过。
- 验证包含：SPA 接收一次原生 Enter 后不导航仍可只读观察；未知操作不重放；接管和后台权限不可绕过；文档失效后实际点击生产界面的“重新打开”，恢复同标签页及原桌面尺寸。
- 用户截图不足以确认当时具体由哪条操作触发，本次修复针对已确认的状态分类和恢复入口缺陷。未验证 arm64 真机；未扩展普通代理链接导航、POST 或重定向支持。

## Fixed

- **Read failures no longer imply a broken page**: separates an unconfirmed action from an invalid document. Snapshot/capture failures or missing scroll replies no longer quarantine the entire page merely because of an error code. The failed action still reports an error and is not automatically repeated.
- **Observe before resuming**: when a click, input or Enter was dispatched but its effect is unconfirmed, snapshot and capture can still inspect the same verified document under the existing grant. New agent mutations and opens cannot clear that uncertainty. The person checks the page and explicitly chooses Resume agent; the earlier action is never replayed.
- **A recovery button that matches the state**: an observable page shows an unconfirmed-action notice with Resume agent. An invalid document offers a working Reopen action instead of a Resume button that must fail. Reopen keeps the tab and desktop resolution; renderer failure retains a recovery entry instead of an endless loading state.
- **Authority boundaries remain intact**: takeover, backgrounding, connection and owner changes still revoke access. Targeted opens of non-selected tabs cannot bypass an unconfirmed action, and a late resume probe cannot clear newer uncertainty.
- **Accurate tool guidance**: `OUTCOME_UNKNOWN` no longer always instructs the agent to reopen. Observation replies explicitly carry `drivable:false` and `observationOnly:true`, rather than claiming the page can be modified.
