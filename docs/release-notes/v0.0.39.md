# v0.0.39 — “所有 App”下任务跟着跳转走

> In all-apps mode a task follows the target when it hands off to another app.

## 改进

- **跳转到别的 App 时，任务会跟过去**：开启“所有 App”后，目标 App 如果自己跳到另一个 App，比如打开 QQ 登录授权或微信支付，任务会跟着切过去继续操作，不再一直等原 App 回来，最后报读取超时（`READ_TIMEOUT`）。切换后，代理必须先重新读一遍屏幕才能操作，旧页面的读屏结果不能再用。系统界面和锁屏仍然不允许；打开 AndChamber 的手机控制页仍会收回授权。
- **`open_app` 可以打开任意允许的 App**：在“所有 App”模式下，代理可以在同一个任务里打开另一个允许的 App。
- **浮窗和通知显示当前 App**：任务跟到哪个 App，浮窗和通知就显示哪个 App 的名字。
- **读取超时后自动重连一次**：出现 `READ_TIMEOUT`、手机连接断开后，App 会在后台自动重连一次。重连不会恢复被中断任务的授权，代理需要重新发起任务。代理收到的提示也改为：先确认已重新连接，再发起新任务，不要重复已经发出过的操作。
- **只选部分 App 时不变**：每个任务仍然只操作一个 App，跳到其他 App 会被拒绝。

## 验证范围

- 在模拟器（API 35 / x86_64）上用独立测试包验证：开启“所有 App”后，先对测试 App 发起任务，再让前台切到另一个 App（日历）。代理在同一个任务、同一个 epoch 里读屏成功，读到的是日历的页面；点击日历里的按钮成功；结束任务正常。
- 读取超时后的自动重连，只在单元测试中验证过，没有在设备上模拟超时。
- 2,157 项 JVM 测试、361 项 Node 测试（360 项通过，1 项原有跳过）、72 项 Python 测试通过；lint 和 debug/AndroidTest 打包通过。
- 还没在真机上复测。

## Improvements

- **Follow the handoff**: in all-apps mode a task continues when the target opens another allowed app (QQ OAuth, WeChat pay, a browser). A fresh snapshot is required after a switch; system UI and keyguard stay refused, and the phone-control page still revokes.
- **`open_app`** in all-apps mode may open any allowed launchable app within the same task.
- **Labels** in the capsule and notification follow the real foreground app.
- **One bounded background reconnect after `READ_TIMEOUT`**; the interrupted lease is not restored. The tool message now says to check `status.connected`, start a new request and never repeat a mutating action.
- **Explicit-list mode is unchanged**: one target per task.

## Verification scope

- API 35 / x86_64 emulator with a separate test package: a task started on the synthetic target followed a switch to another app (Calendar) on the same epoch; snapshot, a tap and finish succeeded.
- The `READ_TIMEOUT` reconnect is covered by JVM tests only, not by an on-device fault.
- 2,157 JVM, 361 Node (360 passed plus one existing skip) and 72 Python tests, Android lint and debug/AndroidTest packaging passed.
- Not re-tested on a real phone.
