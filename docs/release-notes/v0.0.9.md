## 新功能

- **更新 OpenChamber 和 OpenCode**：不再需要“修复”重装整个 Linux 系统。首页会在有新版本时显示“有可用更新”，列出版本变化（例如 OpenChamber 2.4.0 → 2.5.0）。更新会在当前系统的副本中重新安装这两个 npm 包、重建终端支持并检查，然后原子切换；不会重新下载 Linux 基础系统。服务器正在运行时会先停止，更新后自动重新启动。
- 新版本来自 npm registry，只选择与内置版本相同主版本的正式版，排除预发布版本。应用启动时检查，之后最多每 6 小时自动检查一次；“详细信息”里也可以手动检查。无法访问 registry 时，仍会提示 APK 内置的更新版本。
- 更新失败时保留当前版本，服务器照常可用。首页会显示失败原因和技术详情，可以重试或关闭提示。
- “修复”现在安装已安装版本与内置版本中较新的那个，不会把 OpenCode 降级。

## 修复

- **终端无法打开**（`Failed to load native module: pty.node`）：激活环境时，PRoot 的伪硬链接被改写成相对路径，PRoot 无法解析，Node 因此把 `pty.node` 当作 JavaScript 加载。现在这些链接改写为 PRoot 使用的绝对路径（`/data/data/<包名>/...`）。已有安装会在下次启动应用时自动修复，无需重装。

## New

- **Update OpenChamber and OpenCode**: no full Linux reinstall (Repair) is needed anymore. Home shows "Update available" with the version changes (for example OpenChamber 2.4.0 → 2.5.0). The update reinstalls both npm packages in a copy of the current system, rebuilds terminal support, checks the result and swaps it in atomically. The Linux base is not downloaded again. A running server is stopped first and started again afterwards.
- New versions come from the npm registry: stable releases with the same major version as the bundled ones, no pre-releases. The app checks at launch and then at most every 6 hours; Details also has a manual check. When the registry can't be reached, the newer versions bundled in the APK are still offered.
- A failed update keeps the current version, and the server keeps working. Home shows the reason and the technical detail, with Try again and Dismiss.
- Repair now installs the newer of the installed and bundled versions, so it never downgrades OpenCode.

## Fixes

- **The terminal could not open** (`Failed to load native module: pty.node`): environment activation rewrote PRoot's faked hard links to relative paths, which PRoot can't resolve, so Node loaded `pty.node` as JavaScript. The links are now rewritten to absolute paths in the spelling PRoot uses (`/data/data/<package>/...`). Existing installs are repaired on the next app start, without a reinstall.

## Other

- 515 JVM unit tests pass.
- Verified on one arm64 phone with a separate test package: fresh install, terminal, update from 2.4.0 / 2.0.32 to 2.5.0 / 2.1.1, keeping the old version after a failed update, and the link repair of an older install at launch. Only this one device was tested.
- Each update downloads the OpenChamber and OpenCode npm packages again (about 200 packages) and takes several minutes.
