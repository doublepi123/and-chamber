首个预览版本 / First preview release.

## 主要功能

- 在 arm64 Android 设备上原生运行 OpenChamber 2.4.0 + OpenCode 2.0.32（PRoot + Alpine Linux 3.24.1 + Node.js 24），无需 root。
- App 内一键完成安装、启动和自动登录；设置完成后打开 App 直接进入 OpenChamber，服务未运行时会自动启动。
- 前台服务常驻后台，服务异常退出时自动重启；终端功能可用（设备上为 musl 重新编译 `node-pty`）。
- 可选公共目录 `/sdcard/AndChamber/`：存放项目（`/workspace`）和 OpenCode 全局配置，方便用文件管理器或电脑维护；凭据、会话数据库、插件依赖保留在私有目录。
- 支持连接远程 OpenChamber 服务器；明文 HTTP 需要手动确认。

## 已知限制

- 本机运行仅支持 arm64-v8a；x86_64 设备（包括大多数模拟器）只能连接远程服务器。
- 首次设置约需下载 1.2 GB，需要能访问 Alpine 软件源和 npm。
- 公共目录不支持符号链接和可执行权限，需要 `node_modules` 的项目请放在 `/workspace-private`。

## Highlights (English)

- Runs OpenChamber 2.4.0 + OpenCode 2.0.32 natively on arm64 Android (PRoot + Alpine 3.24.1 + Node.js 24), no root.
- One-tap setup, start and automatic sign-in; the app opens straight into OpenChamber and starts the server if needed.
- Foreground service with crash recovery; working terminal (node-pty rebuilt for musl on the device).
- Optional shared folder `/sdcard/AndChamber/` for projects and OpenCode settings; secrets stay private.
- Remote OpenChamber servers, with explicit confirmation for plain HTTP.
