# v0.0.41 — 不需要密码的登录由代理直接完成

> The agent completes sign-ins that need no password or code.

## 改进

- **一键登录、协议勾选由代理自己做**：只要是你交代的任务里的一步，并且不需要密码或验证码，代理会自己勾选“已阅读并同意”，点“一键登录”（例如 QQ、微信显示了账号的快捷登录），在第三方授权页点“同意/允许”，然后继续做，不再停下来请你处理。
- **选账号**：只有你在聊天里点名了要用哪个账号，代理才会去选；不会新建账号，也不会自己挑一个你没说过的账号。
- **仍然交给你处理的情况**：密码输入框（工具本来就不能往密码框里输入）、验证码、支付或其他涉及钱的确认、系统权限弹窗。代理也不会让你把密码发到聊天里。
- 这是给代理的使用规则，不是 App 强制执行的限制。

## 验证范围

- 工具说明的文案测试已更新并通过：361 项 Node 测试（360 项通过、1 项原有跳过），相关 JVM 测试通过，打包通过。
- 代理是否真的按这条规则操作，取决于所用模型，没有在设备上验证。

## Improvements

- **Sign-ins without secrets**: when it is part of the requested task and needs no password or code, the agent ticks the required agreement box, taps one-tap/quick login with the shown account, and taps Agree/Allow on third-party authorization pages, then continues.
- **Accounts**: the agent picks an account only when the person named it in the chat; it never creates accounts or picks one on its own.
- **Still handed to you**: password fields (the tool cannot type into them), verification codes, payments and system permission dialogs. The agent never asks for a password in the chat.
- This is tool guidance, not an enforced native rule.

## Verification scope

- Tool-description tests updated and passing (361 Node tests, 360 passed plus one existing skip), relevant JVM tests and packaging passed.
- Real-model compliance with the guidance was not verified on a device.
